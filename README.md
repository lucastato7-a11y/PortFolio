# 🚀 Portfolio - Lucas

Este es mi portfolio personal, lo armé como proyecto integrador para la materia Programación III. La idea fue ir construyendo un sitio de a poco a lo largo de la cursada: arranqué con la maqueta en HTML y CSS, y en esta última etapa le sumé JavaScript para que deje de ser una página estática y pase a tener interacción real con el usuario.

Acá muestro quién soy, en qué proyectos vengo trabajando, qué tecnologías manejo y dejo un formulario para que me puedan contactar.

## 🛠️ Tecnologías

- HTML5
- CSS3 (con animaciones, efecto glass y diseño responsive)
- JavaScript (puro, sin librerías)
- Google Fonts (Poppins)
- Formspree para que funcione el formulario de contacto

## ✨ Qué le agregué con JS

- **Filtro de proyectos:** los proyectos están guardados en un array y se generan solos en pantalla. Arriba hay botones (HTML, CSS, JavaScript) para filtrar por tecnología.
- **Buscador de skills:** las tarjetas de habilidades también salen de un array, y agregué un buscador que las filtra mientras vas escribiendo.
- **Validación del formulario:** si dejás algún campo vacío o ponés un email mal escrito, te avisa antes de mandar el mensaje. Usé `try/catch` para que si algo falla no se rompa todo.
- **Hover en las tarjetas de proyectos:** al pasar el mouse te muestra qué tecnologías usé en ese proyecto.
- Todo responsive, anda bien en celu también.
